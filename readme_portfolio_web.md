# Portfolio Web Personal — Rodrigo Torrilla

Este proyecto consiste en el desarrollo de una **página web personal tipo portfolio (Single-Page)** diseñada para presentar el perfil profesional, habilidades técnicas, formación académica e iniciativas actuales de **Rodrigo Torrilla** (*Desarrollador Junior / Trainee en Programación*).

---

## Evolución del Trabajo Realizado

A lo largo de nuestras sesiones de trabajo, fuimos transformando un currículum tradicional en una aplicación web moderna mediante distintas etapas iterativas:

1. **Estructuración Inicial (HTML & CSS):**
   * Partimos de la información base de tu currículum (perfil profesional, stack en C++ y Python, nivel de inglés B2, educación y metas) para construir una primera versión semántica y ordenada en HTML5.

2. **Mejora de Paleta y Dinamismo Visual:**
   * Actualizamos el diseño estático inicial incorporando una estética más tecnológica con degradados en tonos azules y cian, indicadores visuales en los encabezados y tarjetas con sombras suaves.

3. **Transformación a Página Web (Dark Mode):**
   * Rediseñamos por completo la estructura para que dejara de verse como un documento de CV y adoptara el formato de una **landing page web moderna**.
   * Implementamos una paleta donde predomina el **negro profundo** (`#05070a`), combinado con tarjetas en tonos oscuros (`#0d1117` / `#121824`), texto en blanco de alto contraste y acentos e iluminaciones en **azul eléctrico**.
   * Agregamos una barra de navegación fija (*sticky navbar*) con efecto translúcido (*glassmorphism*), una sección de portada (*Hero*) con botones de llamada a la acción (*CTA*) y grillas responsivas.

4. **Nueva Sección "Mis Proyectos" y Redacción Profesional:**
   * Incorporamos una sección dedicada a tus iniciativas actuales, optimizando la redacción para destacar su valor formativo y técnico:
     * **Ingreso a la Escuela de Aviación Militar (EAM):** Enfocado en la preparación en ciencias exactas, disciplina operativa y liderazgo.
     * **Perfeccionamiento en Lengua Inglesa:** Formación extracurricular continua orientada a la fluidez y comunicación en entornos internacionales.
     * **Diseño y Ensamblaje de Robótica:** Desarrollo curricular de prototipos robóticos integrando hardware y lógica de programación.

---

## ✨ Características Principales

* **Diseño Responsivo:** Adaptable a pantallas de escritorio, tablets y dispositivos móviles mediante `CSS Grid` y `Flexbox`.
* **Estética Dark Tech:** Interfaz oscura con detalles luminosos y transiciones suaves (`hover`) en tarjetas y botones.
* **Navegación Fluida:** Desplazamiento suave (*smooth scroll*) entre las secciones *Perfil*, *Mis Proyectos*, *Habilidades*, *Experiencia*, *Educación* y *Contacto*.
* **Código Limpio y Autocontenido:** Uso de variables CSS (`:root`) para facilitar el mantenimiento y la personalización de colores.

---

## Tecnologías Utilizadas

* **HTML5:** Estructura semántica del contenido.
* **CSS3:** Estilos personalizados, variables nativas, degradados, `backdrop-filter`, Flexbox y Grid Layout.
